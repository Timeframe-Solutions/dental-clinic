PROJECT BRIEF
Plaza Dental Clinic — Premium Dental Website
Prepared by: Timeframe Solutions
Version: 1.0

════════════════════════════════════════════════════════════════
1. EXECUTIVE SUMMARY
════════════════════════════════════════════════════════════════

Plaza Dental Clinic is a premium dental practice based in Nairobi, Kenya. This project
delivers a conversion-optimised, trust-anchored marketing website designed to generate
appointment requests and WhatsApp inquiries from Nairobi residents seeking quality
dental care.

The website is NOT a patient portal. It is a lead-generation platform — every page,
section, and call-to-action is designed to move visitors toward booking an appointment
or initiating a WhatsApp conversation.

Selling Price:    KSh 75,000
Build Time:       3–4 days
Delivery:         7 days
Stack:            Nuxt 4 · TypeScript · Tailwind CSS · Resend · Vercel

8. SEO STRATEGY
════════════════════════════════════════════════════════════════

PRIMARY KEYWORDS (by page)
  Home:            "Dental Clinic Nairobi", "Best Dentist Nairobi"
  Services:        "Dental Services Nairobi", "Affordable Dentist Nairobi"
  Dental Implants: "Dental Implants Nairobi", "Tooth Implants Nairobi"
  Braces:          "Braces Nairobi", "Orthodontist Nairobi"
  About:           "Plaza Dental Clinic Nairobi"
  Contact:         "Book Dentist Nairobi", "Dental Appointment Nairobi"

ON-PAGE SEO REQUIREMENTS
  • Unique <title> and meta description per page
  • H1 containing primary keyword on every page
  • Schema markup: LocalBusiness, Dentist, MedicalOrganization
  • Open Graph tags for social sharing
  • Sitemap.xml auto-generated (Nuxt SEO)
  • robots.txt configured
  • Google Analytics 4 + Google Search Console
  • Image alt text on all photos

LOCAL SEO
  • NAP (Name, Address, Phone) consistent across site and footer
  • Google Maps embed on Contact page
  • LocalBusiness JSON-LD schema on Home + Contact

9. TECHNICAL REQUIREMENTS
════════════════════════════════════════════════════════════════

FRAMEWORK       Nuxt 4 (app/ directory structure)
LANGUAGE        TypeScript 5
STYLING         Tailwind CSS v4
FORMS           Resend API via server/api/contact.post.ts

IMAGES          Nuxt Image (@nuxt/image) — WebP optimisation
FONTS           Google Fonts (Inter) — self-hosted via @nuxtjs/fontaine

PERFORMANCE TARGETS
  • Lighthouse Performance  ≥ 90
  • Lighthouse SEO          ≥ 95
  • Lighthouse Accessibility ≥ 90
  • LCP                     < 2.5s
  • CLS                     < 0.1
  • FID                     < 100ms

HOSTING CONFIGURATION
  • Vercel Edge Network (global CDN)
  • Environment variables: RESEND_API_KEY, NUXT_PUBLIC_SITE_URL,
